What’s off today no code changed yet

  • Stacked cream emoji blocks — each card has a flat cream thumb strip + giant emoji; feels like a placeholder vs the cleaner onboarding pet cards.
  • Selection chrome mismatch — Customize uses “✓ Current” text; PetSelection uses a corner radio. Two patterns for the same action.
  • Awkward 47% widths — grid uses width: '47%' instead of equal flex/gap like onboarding (gap: 12 + computed card width).
  • CTA hierarchy soft — Save is fine but Cancel is a plain centered text link with no min-height style token; Save weight/radius doesn’t match PetSelection’s primary CTA.
  • Hint is thin — one-line gray text under a redundant “3D companion” heading; doesn’t clarify that preview updates live but persistence needs Save.
  • Blurbs unused — PET_TYPES[].blurb exists but Customize ignores it (onboarding also doesn’t show blurbs, but cards have more breathing room).

Proposed styling-only changes

  • Match Companion cards to PetSelection: sand border, radio corner, no cream thumb strip, slightly taller padding.
  • Optional one-line blurb under label (already in data) for clarity without new logic.
  • Rename section “Companion”; wrap hint in mist panel (like Wardrobe intro).
  • Align Save CTA with PetSelection (54px / 17px ExtraBold / radius 17); Cancel gets explicit tapTarget.min style.
  • Use spacing.* + colors.sand borders; replace hardcoded error #A65D5D if we touch that style block.
